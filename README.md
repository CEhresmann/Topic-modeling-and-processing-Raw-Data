# Тематическое моделирование текстовых данных


[![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/colored.png)](#)

## ➤ Описание

Этот проект предназначен для выполнения тематического моделирования на основе текстовых данных, извлеченных из различных файлов. Основная цель - предобработка и анализ текстовой информации для выявления скрытых тем и закономерностей.


[![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/colored.png)](#-)

## ➤ Структура проекта

- **main.py**: Главный скрипт, запускающий процесс обработки и моделирования.
- **extractTextFromPDF.py**: Модуль для извлечения текста из PDF-файлов, включая обработку изображений и таблиц.
- **data/**: Каталог для хранения исходных данных (PDF, текстовые файлы и т.д.).
- **models/**: Каталог для сохранения обученных моделей тематического моделирования.
- **pyproject.toml**: Файл конфигурации проекта, содержащий зависимости и метаданные.
- **setup.py**: Скрипт для настройки окружения, установки зависимостей и запуска проекта.


[![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/colored.png)](#--)

## ➤ Установка и запуск

1.  **Создание виртуального окружения и установка зависимостей:**
    ```bash
    python setup.py install
    ```
2.  **Запуск проекта:**
    ```bash
    python main.py --input-dir data/
    ```


[![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/colored.png)](#-)

## ➤ Процесс работы

1.  **Извлечение текста**: Скрипт рекурсивно обходит указанный каталог, находит все файлы и извлекает из них текстовое содержимое. Для PDF-файлов используется `extractTextFromPDF.py`.
2.  **Предобработка текста**: Очистка текста от шума, приведение к нижнему регистру, удаление стоп-слов, лемматизация.
3.  **Тематическое моделирование**: Применение алгоритмов (LDA) для выявления тем в текстовых данных.
4.  **Сохранение результатов**: Сохранение модели и результатов анализа в каталог `models/`.
